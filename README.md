# Hangman-Game

This is a simple Hangman game made using Python.

## About the Game

In this game, a word is randomly selected from a list of five words. The player has to guess the word one letter at a time.

The player gets a maximum of 6 wrong guesses. If all the letters are guessed correctly, the player wins. Otherwise, the game ends after 6 wrong guesses and the correct word is displayed.

## Features

* Randomly selects a word from 5 predefined words
* Allows the user to guess one letter at a time
* Shows the letters guessed correctly
* Keeps track of wrong guesses
* Allows up to 6 wrong guesses
* Does not allow the same letter to be guessed again
* Checks whether the entered input is valid

## Technologies Used

* Python
* Random module
* Lists
* Strings
* Loops
* Conditional statements

## How to Run

Make sure Python is installed on your computer.

Run the following command in the project folder:

```bash
python HangmanGame.py
```

Then follow the instructions shown in the terminal.
